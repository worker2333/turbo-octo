# Digital Destiny - 赛博朋克算命系统

一个融合中国传统算命方法与现代技术的赛博朋克风格命理分析平台。该系统整合了紫微斗数、梅花易数和铁板神数三大传统命理体系，并通过现代AI技术提供深入解读。

## 主要特点

- **三大命理系统集成**: 紫微斗数、梅花易数、铁板神数一站式解读
- **AI智能解读**: 支持OpenAI、Claude和Gemini API，提供专业命理解析
- **赛博朋克UI**: 黑灰白配色，流动线条动效，科技感十足
- **可视化展示**: 多种直观图表展示命盘信息
- **交互式问答**: 通过AI回答用户的命理相关问题

## 技术架构

- **前端**: Vue.js + D3.js可视化
- **后端**: Node.js + Express
- **数据库**: MongoDB
- **AI集成**: 支持多个大型语言模型API
- **容器化**: 基于Docker的完整部署方案
